# School-supplied essay starter

`main.tex` is the unmodified contents of `essay_template_latex.tex` from the essay template supplied for TU/e Networks 2IRR20, renamed only so the entry file is `main.tex`. It preserves the two-column IEEE conference layout, three author blocks, paper-title subtitle, abstract instructions, section prompts, and inline example bibliography.

The sample references are template demonstrations, not evidence for a new document. Replace them with verified sources when writing. Course-specific prompts and assessment statements apply only when the actual assignment requires them.

No separate license notice is present in the supplied `.tex` file. It remains attributed school-supplied material and is not relicensed under the repository's MIT license. The source PDF and course submissions are not included.

The starter uses `IEEEtran` from the TeX distribution. The school archive supplied version 1.8b; that class file is not duplicated here. `IEEEtran` has its own LPPL license and attribution.
